# B1 · 强基线：ResNet34-UNet + ImageNet 预训练

| 项 | 值 |
|---|---|
| 代号 | **B1**（Baseline 族；序号 1 = 比 B0 强一档） |
| 一句话 | 只把编码器换成 ResNet34 并加载 ImageNet 权重，其余与 B0 完全一致 |
| 参数量 | 24.53 M（编码器 21.29 M，占 87%） |
| 只改的变量 | **编码器容量 + 预训练**（融合方式仍是 6 通道早融合） |
| 状态 | ⏳ 代码暂在 `model/resnet_unet.py`（`siamese=False`）；待本阶段迁入本文件夹 |

## 与 B0 的口径差异（必须逐条对齐，否则消融不成立）

- 归一化：B0 用数据集统计，B1 必须用 **ImageNet 常数**（预训练权重的 BN 统计在 ImageNet 分布上）；
- 编码器学习率：1e-4（解码器 1e-3）；
- 6 通道 conv1：ImageNet 3 通道权重按 A/B 复制、每份 ×0.5，保持激活量级不变；
- 解码器与 B0 同构（bilinear + skip 拼接 + 双 3×3），所以差异只剩编码器。

## 实测（待迁入本文件夹后补齐分层数字）
