# C1 · 结构对照：BIT（Transformer 时空注意力）

| 项 | 值 |
|---|---|
| 代号 | **C1**（Comparison 族；序号 1 = 第一个对照） |
| 一句话 | ResNet18 + Transformer 时空注意力，回答「为什么不用 Transformer 做主线」 |
| 参数量 | 以权重为准（`BIT_LEVIR/best_ckpt.pt`，60 MB） |
| 状态 | ⏳ **阶段 3**：先直接用已有 ckpt 评测（0.5 h），必要时同协议重训（约 6 h） |

## 为什么是它

BIT 是变化检测里 Transformer 路线的代表，也是面试高频对比项。
它在 LEVIR 上报 ≈0.894 F1，与 M1 的目标线（0.88）同档，
所以「BIT 强还是 M1 强」这个问题的答案**两种都能用**：

- 若 BIT 更好：叙事是「我知道更强的方案，但综合显存/时延/精度我选 M1——这是工程权衡」；
- 若 M1 更好：叙事是「在小数据 + 无大规模预训练条件下，CNN 双流更稳」。

## 建它时的硬约束

1. **同协议**：同一 test 2 048 块、同一阈值、同一评估脚本，否则对比无效；
2. **同归一化**：BIT 权重按 ImageNet 训练 → 用 `imagenet` 常数；
3. 只花 ≤1.5 天：跑不通就放弃，改 C2（SNUNet），不要为一个对照拖垮 W3。
