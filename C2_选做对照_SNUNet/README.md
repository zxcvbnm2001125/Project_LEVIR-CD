## 什么时候做、什么时候不做

- 做：M1 已过 0.88 目标线、W3 还剩 ≥2 天；
- 不做：任何一周落后 >3 天 → 直接砍掉，保 W4 业务线（图斑 + 部署）。
  这是计划 §5 明确写的砍单顺序，不要临时改主意。

## 为什么它只值「选做」

SNUNet 在 LEVIR 上报 ≈0.892，与 BIT 同档，但它带来的**对话价值**与 C1 重叠
（都是「别人家的结构」）。真正稀缺的是 W4 的图斑链路与部署表，不是第三个模型。
