# M0 · 方法族消融参照：孪生 ResNet34 + concat 融合

| 项 | 值 |
|---|---|
| 代号 | **M0**（Method 族；序号 0 = **不显式建模差异**） |
| 一句话 | 双流共享编码器，但融合只用 `cat([f_a, f_b])` —— 没有差分项 |
| 参数量 | 25.23 M |
| 只改的变量 | 相对 B1：**早融合 → 孪生双流**，但暂不加差分 |
| 状态 | ⏳ 代码暂在 `model/resnet_unet.py`（`siamese=True, fusion="concat"`）；待迁入本文件夹 |
| 别名 | 旧代号 `m1-cat` |

## 为什么需要它

M1 相对 B1 会同时改变「单流/双流」与「有没有差分」两件事。M0 把这两件事拆开：
`M0 − B1` = 双流结构本身的贡献，`M1 − M0` = **差分项的净贡献**。
没有 M0，M1 的涨点就无法归因到「显式差分」这个卖点上。

参数上 M0 比 M1 少 0.35 M（融合 1×1 卷积少了 512 个通道的输入），
所以「M1 更强」不能用「参数更多」来解释——这一点在面试里要主动提。
