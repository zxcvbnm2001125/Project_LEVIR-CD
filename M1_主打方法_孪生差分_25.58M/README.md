# M1 · 主打方法：孪生 ResNet34 + 逐层特征差分融合

| 项 | 值 |
|---|---|
| 代号 | **M1**（Method 族；序号 1 = **差分 + 原特征**，主推配置） |
| 一句话 | 共享编码器分别编码 A/B，每层融合 `cat([f_a, f_b, \|f_a−f_b\|])` 后 1×1 压回原通道 |
| 参数量 | 25.58 M |
| 相对 M0 只多 | 0.35 M（融合层的输入从 2×ch 变 3×ch） |
| 状态 | ⏳ 代码暂在 `model/resnet_unet.py`（`siamese=True, fusion="diff_concat"`）；待迁入本文件夹 |
| 别名 | 旧代号 `m1` |

## 这是简历上的模型

三句话口径（面试稿）：

1. **为什么差分**：变化检测的本质是「找不同」，`|f_a−f_b|` 把差异显式编码成特征，
   网络不必自己在 6 通道里猜「哪两张图对应」；
2. **为什么保留 concat**：差分只保留「差异强度」，丢掉了「差异出现在什么样的地物上」，
   原特征提供上下文，两者互补（M2 的消融证实这一点）；
3. **为什么共享权重**：编码器只算一份 21.3 M，且强制 A/B 进同一特征空间，避免过拟合。

## 实测（冒烟）

| 项 | 值 |
|---|---|
| FLOPs | 30.8 G（双流，比 B0 +10%） |
| 单张时延 | 11.9 ms |
| 训练峰值显存 | bs24 → 3.0 GB，bs48 → 5.9 GB（不安全） |
| 单 epoch | 156 s |
| 冒烟 val F1（**1 epoch**） | **0.8334**（IoU 0.7144，空块误报 2.96‰） |

> 1 epoch 就到 0.8334、空块误报只有 B0 的 29%——差分不只是抬 F1，还直接压住伪变化。
> 但这是 1 epoch 的 val 数字，不构成结论，正式结果见 `EXPERIMENTS.md` #2。
