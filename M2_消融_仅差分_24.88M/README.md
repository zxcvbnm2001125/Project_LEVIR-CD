# M2 · 方法族消融：孪生 ResNet34 + 仅差分

| 项 | 值 |
|---|---|
| 代号 | **M2**（Method 族；序号 2 = **只有差分**，丢掉原特征） |
| 一句话 | 融合只剩 `cat([\|f_a−f_b\|])`，检验「原特征是否必要」 |
| 参数量 | 24.88 M（比 M1 少 0.70 M） |
| 只改的变量 | 相对 M1：融合输入 3×ch → 1×ch |
| 状态 | ⏳ 代码暂在 `model/resnet_unet.py`（`siamese=True, fusion="diff"`）；待迁入本文件夹 |
| 别名 | 旧代号 `m1-diff` |

## 为什么需要它

M1 的融合是「原特征 + 差分」并联。如果只用差分也能得到同样的 F1，
说明原特征是冗余的——那 M1 的设计就该简化（这本身是一个有价值的负面结论）。

反过来，如果 M2 明显掉点，说明**差分只提供「差异强度」，不提供「差异长什么样」**，
M1 的并联设计就有据可讲。两种结果都能写进报告，不是可有可无的一行。
